# 🇵🇭 Консьерж-сервис на Филиппинах

Одностраничный сайт (лендинг) сервиса релокации, подбора жилья и сопровождения на Филиппинах (Себу, Лапу-Лапу, Бохол, Панглао).

## 🚀 Особенности
- **Адаптивный дизайн:** Оптимизирован под мобильные устройства и десктоп.
- **Интерактивный кейс:** 3-карточный горизонтальный свайпер с нативным `CSS Scroll Snap` и просмотром фотографий в модальном окне (Lightbox).
- **SEO & Social Sharing:** Настроены Open Graph, Twitter Cards и SVG Favicon.
- **Чистый стек:** Vanilla HTML5 / CSS3 / ES6 JavaScript без лишних внешних библиотек.
- **Готовность к GitHub Pages:** Включен `.nojekyll` и относительные пути к медиафайлам.

## 📦 Структура проекта
```text
.
├── index.html        # Главная страница
├── favicon.svg       # Иконка сайта
├── img/              # Оптимизированные изображения и фото кейса
├── .nojekyll         # Маркер для GitHub Pages
└── README.md         # Описание проекта
```

## 🌐 Публикация на GitHub Pages
1. Репозиторий проекта:
   [github.com/oae214713-lang/philippines-concierge](https://github.com/oae214713-lang/philippines-concierge)
2. В репозитории на GitHub перейдите в **Settings** → **Pages**.
3. В секции **Build and deployment** выберите:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
4. Нажмите **Save**. Сайт будет доступен через 1-2 минуты по адресу:
   👉 **`https://oae214713-lang.github.io/philippines-concierge/`**
